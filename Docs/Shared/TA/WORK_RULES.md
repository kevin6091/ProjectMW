# TA 공유 작업 규칙

Art/TA 작업은 이 폴더의 개발명세·마일스톤·마이그레이션 계획을 먼저 읽는다. 문서들은 같은 계약과 예산의 다른 관점이며 작업 시간을 중복 계산하지 않는다.

- 에셋 제작 전 소켓 로컬 축, cm 단위, 폭, 주행 콜리전, 배치 Footprint, 체크포인트/안전 복귀 위치, 설치 슬롯의 소비 코드를 확인한다.
- 주행 충돌·서버 배치 검사·Editor 정적 검사는 각각 검증 범위가 다르다. Validator 통과만으로 멀티플레이 주행까지 완료했다고 판정하지 않는다.
- Runtime DataAsset은 개발과 공유하는 계약이다. 해당 스키마·게임플레이 의미를 바꾸면 개발 공유 문서와 영향을 받는 Client/Server 지침도 읽고 소비 코드를 함께 확인한다.
- Editor 전용 도구와 Runtime 의존성을 분리한다. TA 코드/자동화 작업은 Art와 개발 공통 필독을 함께 적용한다.
- [Git 공통 규칙](../GIT_COLLABORATION_GUIDE.md)에 따라 재임포트·이름 변경·일괄 수정도 경로 예약과 리뷰를 거친다. 에셋 변경 잠금은 main 반영/인계 후 해제한다.
- 변경한 에셋의 경로·설정·재현 가능한 검사 결과를 남긴다. 바이너리 원본과 기존 참조를 확인하고 필요한 에셋만 수정한다.
- 사용 가능 리소스와 실제 검증 범위를 명세대로 기록한다. 자동화 개선 수치는 동일 조건에서 측정했을 때만 결과로 적는다.

일별 TA 원본은 [TA 마일스톤](01_TA_마일스톤_4주.md), 규격은 [TA 개발명세](MakeWay_TA_개발명세서_v1.0.md), 이전 절차는 [TA 마이그레이션](03_TA_마이그레이션_실행계획.md)을 따른다.
