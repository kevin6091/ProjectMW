# 아이템 상자 대기·획득 연출

기준 `origin/main@41ac179`, 작업 브랜치 `feature/item-pickup-presentation`. 트랙 선택·배치 PR #24에 대한 코드 의존은 없다.

## 수정 위치

| 위치 | 처리 |
| --- | --- |
| [MWPickupBox.h](../../Source/MW/Gameplay/Items/MWPickupBox.h) | 상자 Details의 `MW / Items / Presentation`에서 떠 있는 높이, 상하 진폭과 주파수, 회전, 기울기, 뚜껑 각도, 열림·퇴장 시간을 조절한다. |
| [MWPickupBox.cpp](../../Source/MW/Gameplay/Items/MWPickupBox.cpp) | 시작할 때 기존 메시·뚜껑·손잡이의 월드 자세를 보존하면서 렌더 전용 루트에 연결한다. 대기 중 이 루트만 움직인다. |
| [MWPickupBox.cpp](../../Source/MW/Gameplay/Items/MWPickupBox.cpp) | 서버 지급 승인 후 충돌을 즉시 끈다. 기존 `bAvailable`을 받은 각 창에서 뚜껑 메시의 원점과 손잡이가 같은 경첩을 기준으로 회전하고 외형의 크기를 줄여 숨긴다. 숨긴 상자와 Dedicated Server에서 연출 Tick은 정지한다. 뚜껑 메시를 지정하지 않은 상자는 즉시 숨기는 기존 동작을 유지한다. |

기존 레벨에 저장된 일부 메시가 충돌 루트에 직접 붙어 있었다. 최초 PIE에서 연출 루트가 메시를 움직이지 못해, 기존 인스턴스를 재저장할 필요 없이 런타임에 올바른 부착을 복구했다. 정상적으로 부착된 인스턴스의 상대 배치는 유지한다. 상자 획득 트리거와 아이템 지급·사용 판정은 기존 코드를 사용한다.

## 참고 영상과 적용 범위

첨부한 Switch 영상 9:59–10:04에서 주행 경로 위에 떠서 기울어진 상자들이 보인다. 이번 작업은 이 대기 효과와 획득 시 뚜껑 열림을 프로젝트의 기존 상자 메시로 구현했다. 테스트 맵 `L_Dev_Drive_ItemPickup`의 상자 세 개를 사용했다. 일반 경기에 상자를 배치하는 런타임 경로는 현재 구현되어 있지 않다. 생성 위치·빈도·재등장은 이후 경기 규칙 작업의 범위다. 맵, 메시, 블루프린트 및 설정 파일은 수정하지 않았다.

## 검증 결과

- UE 5.8.4 `MWEditor Win64 Development` 빌드 성공. 최종 빌드에서 `MW.Items.PickupAndUse` 통과. Racing 전 지급 차단, 슬롯이 찼을 때 상자 보존, 부스터 지급·사용·중복 거절을 확인했다.
- UVCS cs:80을 기준으로 준비한 복제본과 원본 작업 폴더 사이에서 테스트 맵과 상자 메시 세 개의 SHA-256이 일치했다. 테스트 맵 해시는 `ff5b0ec5798a2f9282596ab32992465b1147aad9a5975b5fe8ca822e82107cd4`이다.
- Cua Driver로 리슨 호스트 P1과 클라이언트 P2·P3의 PIE를 띄웠다. 뷰포트는 각각 794×514, 1000×562, 1000×562였다. 세 창에서 대기 중 외형 높이 26.0~42.0cm와 회전을 관측했다. 가운데 상자의 트리거는 월드 좌표 `(-1800, 0, 40)cm`에 유지됐다.
- 호스트 차량이 가운데 상자와 중첩되자 호스트에게만 부스터가 지급됐다. 세 창 모두 가운데 상자의 뚜껑이 열리는 동안 충돌이 꺼졌고, 105°에 도달한 뒤 해당 외형이 숨겨졌다. 양옆 상자는 계속 표시됐다. 호스트 창의 Space 입력 후 인벤토리가 비었다.
- 테스트 맵의 차량을 서버에서 가운데 상자 위치로 이동시켜 기존 중첩 경로를 재현했다. 세 창에 고정 카메라를 두고 열린 프레임을 캡처할 때만 PIE 시간 배율을 낮췄다. 일반 경기 중 주행으로 상자를 찾는 흐름은 일반 코스 배치 기능과 함께 검증해야 한다.

실행 기록은 작업 폴더의 `Build-Editor.log`, `automation-item.log`, `pie.log`, `verified-pickup.json`과 Cua Driver의 `idle-p*.png`, `open-p*.png`, `after-p1.png`에 남겼다.
