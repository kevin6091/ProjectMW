# 롤러 차량 표시 높이 전환 보간

기준은 `fix/roller-pivot@8f4287e`와 UVCS cs:82다. 이전 차체 표시 보정은 프레임마다 새 높이를 바로 적용했다. 직전과 같은 접지 상태에서도 바퀴가 원통 끝단에 도달하거나 원통 사이를 지날 때 읽는 높이가 바뀌었다. 접지 검사가 한 프레임 비면 목표 높이가 즉시 0이 됐다.

## 수정 위치

- `Source/MW/Gameplay/Vehicle/MWVehiclePawn.cpp`의 `UpdateRollerBodyPresentation`에서 기존 높이 응답 설정으로 보간 시간을 구한다. 실제 바퀴 위치와 현재 평면 속도로 한 보간 시간 뒤의 위치에서 같은 롤러 표면을 조회한다. 앞쪽 바퀴가 원통에 닿기 직전부터 보정을 시작할 수 있다.
- `MWVehiclePawn.h`의 차체 표시 상태에 보정 높이와 속도를 보관한다. 높이 목표가 바뀌면 언리얼의 임계 감쇠 보간으로 이전 프레임의 높이와 속도에서 이어간다. 접지가 잠시 끊기거나 구간을 벗어나면 0으로 부드럽게 복귀한다. 차량의 기존 표시 초기화 경로에서는 두 상태를 초기화한다.
- 적용 대상은 `BodyPresentation`이다. `DrivePresentation`의 카메라, 충돌 루트, 서버·예측 이동과 롤러의 밀기 설정은 기존 경로를 사용한다. 새 에셋이나 차종별 보정값을 추가하지 않았다.

## 검증

- UE 5.8.4 Editor 빌드 성공. 첫 빌드의 컴파일러 메모리 오류는 빌드 병렬도를 낮춘 뒤 재현되지 않았다.
- Cua Driver로 호스트와 원격 두 창을 열었다. 기록된 중앙 원격 차량은 보정의 최고 높이 68.06cm에서 62.38cm로 바뀌었고, 높이가 여러 프레임에 걸쳐 적용됐다. 좌측과 중앙은 접지한 채 출구를 통과했다. 우측은 원본과 같이 롤러에서 벗어났다.
- 카메라의 부모 관계는 같았고 표시 X·Y 오프셋은 계측에서 0cm였다. 롤러 외형과 주행 충돌을 포함한 원본 에셋 7개의 SHA-256이 UVCS cs:82와 일치했다.

| 주행·구간 | 기준본 최대 표시 Z 차이 | 보간본 최대 표시 Z 차이 |
| --- | ---: | ---: |
| 중앙 원격 A 진입 | 65.45cm | 19.18cm |
| 중앙 원격 중간 | 10.42cm | 5.97cm |
| 중앙 원격 B 이탈 | 51.69cm | 16.29cm |
| 좌측 호스트 중간 | 18.43cm | 4.76cm |

표는 해당 차량을 조작하는 창에서 측정했다. 중앙 차량의 보정은 소유자 창과 호스트에서 계측했고, 나머지 원격 창에서는 해당 차량의 연속 표본이 없었다. 수치는 별도로 진행한 두 주행의 표시 높이 비교다.

차체 Z 표시값의 연속 관측 차이를 비교한다. 65ms 이내에 실제 차량 위치가 300cm 이하로 이동한 샘플만 포함했으며, 실제 차량 Z 차이도 함께 기록했다. 주행은 기존 개발맵에서 같은 시작 위치와 무조향 가속을 사용했다.

캡처·빌드·주행 로그는 로컬 검증 폴더 `work/roller-pivot-audit/visual-blend-fix`에 있다. 수치 원본은 `visual-blend-comparison.json`이다.
