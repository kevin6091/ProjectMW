# 체크포인트 복귀와 경기 점수 연출 검증

`feature/match-results-tally`에서 `3c119b7` 이후의 변경을 기록한다. Client·Server의 기존 카메라, 점수 복제 및 체크포인트 복귀 경로를 사용한다.

## 변경 위치

| 위치 | 변경 내용 |
| --- | --- |
| `Source/MW/UI/Gameplay/MWMatchResultsWidget.cpp` · `.h` | 서버 지급 내역을 라운드 소개, 체크포인트별 지급, 완주, 선착 보너스 순으로 반영한다. 같은 항목의 모든 열은 같은 점수 속도로 올라가고, 실제 지급량이 적은 열은 먼저 멈춘다. 정산이 끝나면 열과 점수를 유지한 채 이름 위치에 누적 순위를 표시한다. 시상 카드는 1·2·3위 순으로 열리고 이름·점수·차량 썸네일은 각 카드 안에서 늦게 나타난다. |

## 3인 PIE 결과

UE 5.8 `MWEditor Win64 Development` 전체 빌드 후 Cua Driver로 두 클라이언트와 리슨 서버 창을 확인했다. 검증용 코드로 목표를 550점으로 줄이고, 기존 서버 설치 절차에 의도를 제출해 두 라운드의 실제 코스를 구성했다. 차량을 실행 중인 체크포인트·결승 트리거에 옮겨 실제 중첩 이벤트로 집계했다. 복귀는 코스 아래로 옮겨 기존 실패 판정을 통과시켰다. 수동 랩 주행을 통한 검증은 이 기록에 포함되지 않는다.

- **가산 속도**. `완주 점수`에서 세 열이 9점씩 표시된 뒤 우측 열이 50에서 멈췄다. 그때 좌·중앙 열은 호스트 62점, 클라이언트 63점이었고 세 창 모두 150·150·50점으로 끝났다. 우측 열이 멈춘 것이 처음 관측된 표본과 전체 정지 표본의 차이는 약 0.30초다. 두 라운드에서 `누적 순위`로 바뀌어도 참가자 슬롯과 값이 유지됐다. [50점 열 정지](Evidence/RacePresentation/score-short-column-stopped.jpg) · [전체 정지](Evidence/RacePresentation/score-all-columns-stopped.jpg) · [마지막 라운드 누적 순위](Evidence/RacePresentation/round-positions.jpg)
- **체크포인트**. 일반 통과에서는 100점이 적립되고 차량 카메라가 유지됐다. 낙하 후 P1과 P2는 실제 슬롯으로 복귀했고, 소유 창마다 0.8초 대기가 시작됐다. 서버 표본에서 약 0.83초 뒤 두 차량 모두 주행 권한을 되찾았으며 체크포인트 수는 그대로였다. 첫 실행에서 복귀 슬롯 외곽선을 닫는 `TArray::Add`가 배열 자기 원소를 참조해 에디터가 종료됐다. 닫는 점을 값으로 복사한 뒤 새 빌드에서 두 참가자의 복귀 및 완주까지 확인했다. [일반 통과 직후](Evidence/RacePresentation/checkpoint-pass.jpg) · [복귀 안내와 슬롯](Evidence/RacePresentation/checkpoint-recovery.jpg) · [복귀 안내 종료](Evidence/RacePresentation/checkpoint-resumed.jpg)
- **최종 시상**. 세 창의 확정 순위와 점수는 1위 P2 700점, 2위 P1 400점, 3위 P3 200점이었다. 1위 카드의 첫 공개 표본을 기준으로 2위는 약 0.20–0.25초, 3위는 약 0.36–0.41초 뒤 보였다. 이름·점수·차량 썸네일의 투명도는 카드보다 늦게 올라갔다. 금·은·동 메달과 `Standings` 유지가 세 창에서 확인됐다. ## 화면 비교에서 남은 차이

- 원본은 네 열과 약 17.38초의 집계 화면을 보인 사례다. ProjectMW는 이번에 세 열을 보였고, 서버의 3초 결과 단계 안에서 가산과 순위 유지 시간을 나눴다. 원본과 단계 순서·막대 정지 동작을 비교했으며 화면 지속 시간은 다르다.
- 원본의 복귀 장면에는 주황색 화면 효과와 슬롯의 파편이 있다. ProjectMW는 기존 주행 카메라에서 한 차량의 흰 슬롯과 대기 안내를 표시한다. 하단 복귀 배지는 비어 있는 아이템 슬롯 일부와 겹친다.
- 원본은 1위판 이후 약 0.20초에 2위판, 약 0.40초에 3위판이 보인다. ProjectMW의 카드 시차는 이 구간과 가깝다. 원본은 약 10도 기울어진 판과 3D 차량을 사용하며 메달·판·차량이 따로 들어온다. ProjectMW는 메달이 들어간 수평 카드와 차량 썸네일을 사용한다. 이번 PIE 코스에서는 높은 조각과 철골이 결승선 일부를 가렸다. [결승 카메라](Evidence/RacePresentation/finish-camera.jpg)
- 호스트는 1920×1080 경계의 창에서 관찰했다. Windows 제목줄을 포함한 Cua Driver 원본 PNG는 1918×1078이며, 첨부 JPEG는 사방에 검은 1픽셀을 더해 1920×1080으로 저장했다. 게임 뷰포트 기록은 1914×1042이고 클라이언트 두 창은 800×482였다. 영상과 PIE의 경기 데이터와 뷰포트가 달라 위치는 구도 기준으로 비교했다.
