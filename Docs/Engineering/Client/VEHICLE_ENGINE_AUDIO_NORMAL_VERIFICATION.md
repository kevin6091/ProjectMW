# 차량 엔진음 정상 코스 검증

2026-11-23 KST · `feature/vehicle-engine-audio` · 실행 기준 `932b8f8` · UVCS 엔진음 `cs:66`

Cua Driver로 3인 로비에서 차량 선택 후 세 명 모두 직선 조각을 설치했다. 이전 검증의 직행 경기 대신 정상 설원 코스의 실제 출발선에서 Racing에 진입했다. Windows 오디오 장치가 창마다 생성됐다. 트랙 배치에서는 차량별 엔진 루프가 없었고, 주행 단계의 세 창에는 각 차량의 루프가 1개씩 생성됐다.

| 검증 | 결과 |
| --- | --- |
| Editor Win64 Development | 빌드 성공 |
| 정차·가속·감속 | 같은 FRED의 정차 피치/게인은 0.82/0.10, 가속 최대값은 호스트 1.26476/0.24151, 원격 두 창 1.16586/0.21005였다. 테스트 주행에서는 기존 차량 입력 구조체로 가속과 감속을 줬다. |
| 거리 감쇠 | 보류. 임시 청취점 오버라이드의 첫 출력에서는 외곽에서 무음이 됐으나 근거리 복귀 직후 출력이 돌아오지 않았다. 두 번째 오버라이드와 기본 주행 카메라에서는 가까울 때와 멀 때의 전체 출력이 비슷했다. 임시 개별 서브믹스 녹음이 무음이어서 차 한 대의 신호를 독립적으로 분리하지 못했다. 감쇠가 실패한다고 판정할 근거와 통과 근거가 모두 부족하다. |
| 종료 | Cua Driver로 PIE 종료와 세 창 닫힘을 확인했다. 실경기 완주 후 루프 종료와 참고 영상과의 청감 대조는 미확인이다. |
| 통합 | 개별 브랜치에 보존. 실제 감쇠·복귀·종료를 입증한 다음 Niagara와 세 파일의 충돌을 해소하고 함께 재실행한다. |
