# 트랙 설치 직전과 직후 프레임 비교

2026-11-23 · 로컬 `feature/presentation-integration` · UE 5.8.4 Win64 Development Editor

## 비교 조건

사용자 제공 `2026-10-30 13-56-11.mp4`에서 1:43.900–1:45.133의 원본 60fps 프레임을 추출했다. Cua Driver로 기준 `2b5ff19`와 수정 빌드를 각각 일반 설원 3인 PIE에서 실행했다. 같은 뷰포트와 카메라에서 P1 직선 뒤 P3 45도 곡선을 놓는 장면을 Cua Driver로 녹화했다. 각 녹화의 PTS와 설치 로그를 따로 읽었으며, 청사진 미리보기에서 실제 도로로 바뀐 처음 보이는 프레임을 비교 기준으로 삼았다.

| 원본 시각 | 실제 관찰 |
| --- | --- |
| 1:44.117 | 긴 곡선 구간이 와이어프레임이다. |
| 1:44.133 | 실제 도로와 노란 섬광이 같은 프레임에 보인다. 섬광은 설치한 긴 구간에 여러 곳으로 나뉜다. |
| 1:44.317–1:44.450 | 주황색 불꽃과 짙은 연기가 설치 지점들을 가린다. |
| 1:44.566 | 연기 옆에서 도로를 가로지르는 금속 골조의 가로대와 사선대가 보인다. |
| 1:44.900 | 연기가 옅어진 뒤 골조의 바닥 접점이 보인다. |

기준 PIE의 P3 곡선은 녹화 PTS 8.400초에 실제 도로가 됐다. 8.533초에 짧은 상태의 골조가 보였고 8.633초에는 길게 내려왔다. 이 구간에 설치 섬광·연기는 없었다. 처음 보이는 골조의 높이가 이어지는 프레임에서 변한다는 점도 원본 화면의 인상과 달랐다.

## 수정 위치

- `Config/DefaultGame.ini`에서 기존 프로젝트의 `FXS_MW_Track_Laid_VFX_70dac181`과 골조 공개 간격 `0.40초`를 지정한다. FX는 UVCS `cs:68` 서버와 해시가 같으므로 기존 에셋을 재사용한다.
- `MWTrackConstructionPlacement.cpp`는 설치 승인과 원격 설치 목록 수신 뒤 기존 확정 좌표를 반영하고 로컬 표시용 알림을 보낸다. 설치 판정과 RPC에는 값을 추가하지 않았다.
- `MWEnvironmentGameplay.cpp`는 건설 컴포넌트가 준비됐을 때 알림을 연결하고 월드 종료 시 해제한다. 첫 수정본에서 맵 초기화 중 GameState와 컴포넌트 준비 시점이 달라 접근 오류가 났다. 컴포넌트를 약한 참조로 추적하고 실제 생성된 후 구독하도록 고쳤다.
- `MWTrackSupports.cpp`는 골조 위쪽의 실제 노면에서 기존 섬광을 한 번 재생하고, 지연 뒤 층 전체를 등록한다. 도로 아래 접점은 기존 고정 도로 충돌을 사용한다. 트랙 BP에 받침 폭이 작성된 경우 도로 폭 제한 안에서 그 값을 사용한다.
- 기존 인스턴싱 경로에서는 공유 금속 재질의 사용 플래그가 비어 게임에서 기본 재질로 바뀔 수 있다는 경고가 있었다. 최종 구현은 일반 StaticMeshComponent로 공유 재질을 그대로 읽는다. 최종 PIE에서 회청색 골조가 표시됐고 해당 경고가 재발하지 않았다.

## 최종 3인 PIE

| P3 영상 PTS | 원본 기준과 비교한 화면 |
| --- | --- |
| 14.867초 | 확정 직전의 곡선 고스트. 곡선 하부 골조는 아직 없다. |
| 14.967초 | 실제 도로가 처음 보이고 노면에 옅은 빛과 밝은 점이 나타난다. |
| 15.167초 | 도로는 설치됐고 새 골조는 공개하기 전이다. |
| 15.267초 | 회청색 골조가 바닥까지 완성된 형태로 처음 식별된다. 앞서 보였던 짧은 중간 높이 단계는 계측에서도 사라졌다. |
| 16.067초 | 설치된 곡선과 골조가 유지된다. |

원본 클립은 60fps다. Cua Driver 영상은 프레임 간격이 가변이고 기준·최종 캡처 평균은 각각 14.96fps, 13.75fps였다. 영상 수치는 눈으로 첫 식별 가능한 프레임 사이의 PTS 차이다. 엔진 로그에서 곡선의 효과 생성부터 골조 등록까지는 창별 게임 시간 0.420–0.437초였다.

| 장면 | 같은 도로 아래 접점 XY(cm) | 기준 → 최종 폭 |
| --- | --- | ---: |
| 직선 | (2760.390, 450.000) | 2526.78 → 2370.19cm |
| 45도 곡선 | (7204.367, 83.885) | 2326.54 → 2326.54cm |
| 경사 | (9823.684, −2456.767) | 2513.73 → 2370.19cm |
| 자동 도착 조각 | (12409.984, −5043.066) | 2518.33 → 2518.33cm |

직선·경사에서 읽은 폭 2370.19cm는 두 BP의 기존 받침 메시와 컴포넌트 스케일로 계산했다. 곡선·도착 조각은 유효 도로 폭을 사용했다. 세 창 모두 네 골조가 처음 그려질 때 바닥 Z=0이었고, 사용 재질과 충돌 비활성 상태가 일치했다. 확정된 코스는 5조각이었다. 세 명이 실제 출발선에서 차량을 소유한 채 `Racing`에 진입했고 클릭 재판정과 서버 설치 위치 차이는 0.000001cm 미만이었다.

최종 Editor 빌드와 기존 `MW.Construction.PreviewMatchesSnap` 자동화가 통과했다. 세 창을 함께 띄운 실행에서는 비디오 메모리 경고가 있었다. 패키지 실행은 검증 범위에 포함하지 않았다.

## 원본과 일치 판정

골조가 완성된 상태로 처음 보이는 순서와 원래 금속 재질은 확인했다. 원본의 여러 지점에서 터지는 강한 주황색 불꽃과 짙은 연기는 최종 PIE 프레임에서 같은 수준으로 확인되지 않았다. 원본은 사막의 긴 복합 곡선이며 이 테스트의 운영 후보는 설원의 직선·45도 곡선·경사다. 각 받침의 실제 폭과 긴 조각 안의 위치·개수를 같은 조건으로 증명할 수 없다. 일치 조건이 남아 있어 푸시는 보류했다.
