# 트랙 고스트 흔들림 · 혼합 DPI 재검증

2026-11-23 KST · UE 5.8 Win64 Development Editor · 설원 `L_Dev_Drive` · `feature/track-held-sway`의 스냅 보정 반영 기준 `47ef5a8`

## 수정 위치와 동작

`Source/MW/Gameplay/Construction/MWTrackPlacementViewComponent.{cpp,h}`의 `FPointerSample`, `FHeldSway`, `UpdateLocalPreview`, `UpdateHeldSway`가 사용자의 가로 포인터 속도를 와이어프레임의 작은 기울기로 바꾼다. `GetProjectedHorizontalDelta`는 원격의 자유 이동 미리보기에서 포트 중심의 가로 이동을 각 창의 카메라로 투영한다. `MWTrackPreview.{cpp,h}`의 와이어프레임 그룹을 원래 자세 기준으로 기울이므로, 루트와 연결 포트가 설치 계산의 기준을 유지한다. 이번에는 기존 흔들림 기능에 검증된 스냅 보정을 반영하고 함께 실행했다.

10월 30일 멀티플레이 영상 01:42.70–01:44.10에서는 자유 이동 중 고스트가 움직이고 정지한 고스트에는 반복 좌우 흔들림이 보이지 않는다. 영상에 입력과 3D 각도가 없어 각도와 복귀 시간은 ProjectMW의 기존 설정을 사용했다.

## 3인 PIE 결과

Editor 빌드 성공. UVCS `cs:64` UI 파일 10개를 서버 해시와 대조했다. Cua Driver로 일반 로비에서 세 차량을 선택하고 직선(P1), 45도 곡선(P3), 경사(P2)를 설치했다. 곡선 측정 당시 P1은 594×322 / UE DPI 0.444, P2는 994×610 / 0.564, P3은 1920×1000 / 0.926이었다.

세 창 모두 빠른 이동에서 기울기가 커지고 방향을 반대로 바꾸면 중앙값의 부호도 바뀌었다. 원격 창의 순간 각도는 수신한 이동과 뷰포트 투영을 사용하므로 소유 창의 수치와 차이가 난다. 곡선 정지 상태에서 세 창 모두 추가 기울기 0° 및 포트 중심 이동 0.0000cm였다. 경사 Q/E 동안 세 창 모두 추가 기울기는 0°였고 포트 중앙 이동은 최대 0.004cm였다.

세 조각 모두 클릭 재판정과 서버 설치 위치가 0.000001cm 이내에서 일치했다. 최종 코스는 시작과 도착 조각을 포함한 5조각이었고, 세 명 모두 배정 차량을 소유한 채 실제 출발선에서 `Racing`에 진입했다. 출발선 캡처는 창별로 순서대로 촬영해 P1은 이미 출발 구간을 지나 이동 중이었다. 세 창을 동시에 띄운 환경에서 비디오 메모리 경고가 있었다.
