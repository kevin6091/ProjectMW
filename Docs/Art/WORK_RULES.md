# Art 작업 규칙

공용 문서와 `Docs/Shared/TA` 전체를 먼저 읽은 뒤 에셋을 제작·수정한다.

- 대상은 메시·재질·텍스처·리깅·VFX·임포트 설정·콜리전·소켓·트랙 메타데이터다.
- 최종 외형보다 실제 소비 규격과 참조를 먼저 확인한다. 소켓 축·단위·피벗·폭·충돌·설치 슬롯은 TA 공유 계약을 따른다.
- Content 배치와 이름은 [공용 폴더 기준](../Shared/CONTENT_STRUCTURE.md)을 따른다. 전용 리소스는 해당 Gameplay 기능의 Art, 공용 리소스는 Shared에 둔다. 차량 애니메이션은 Vehicles/Animation에 두며 타입만으로 최상위 폴더를 반복 생성하지 않는다.
- [Git 공통 규칙](../Shared/GIT_COLLABORATION_GUIDE.md)에 따라 바이너리는 실제 경로별 한 명만 수정하고 잠금/중앙 예약과 PR 인계를 관리한다.
- 기존 에셋의 `.uasset`/`.umap` 소유 영역과 참조를 확인하고 필요한 파일만 수정한다. 공유 테스트 맵을 임의로 재구성하지 않는다.
- Runtime 동작이나 데이터 계약을 함께 바꾸면 해당 Client/Server 문서까지 먼저 읽는다. Editor 자동화 코드를 만들면 개발 공통 필독도 추가한다.
- 완료는 임포트 성공만으로 판단하지 않는다. 변경 성격에 맞춰 시각 확인·에셋 검사·스냅·주행·패키지 참조를 검증하고 실제 수행 결과를 적는다.
